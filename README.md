# 🧾 POS System

A full-featured Point-of-Sale (POS) system built with **Laravel** — designed for retail shops, small businesses, and multi-user environments.

## ✨ Features

- 🛒 **Product & Inventory Management** — Add/edit/delete products, stock tracking, low-stock alerts
- 💳 **Sales & Invoicing** — Create invoices, take payments, print receipts
- 👥 **Customer Management** — Track customers, credit/udhaar system
- 🚚 **Supplier Management** — Manage vendors, track payables
- 📦 **Purchases** — Record purchases and stock-in
- 💰 **Expenses** — Track business expenses by category
- 🧾 **Udhaar / Credit System** — Manage customer credit, partial payments
- 📊 **Reports** — Sales, purchases, stock, profit/loss, customer udhaar
- 🔐 **Authentication & Roles** — Multi-user with role-based permissions
- ⚙️ **Store Settings** — Customize store info, currency, tax, receipt
- 💾 **Backups** — Database backup & restore
- 🌙 **Dark Mode** — Light/dark UI toggle
